끓임 시간 계산기

물의 양과 냄비, 시작 온도를 넣으면 물이 끓기까지 걸리는 시간을 알려드려요. 라면 물 끓이기는 물론 다양한 조리에 활용해보세요.

물의 양500 ml
냄비 재질
시작 물 온도20°C
냉수 실온 온수
--:--
표시 범위(15분)를 넘었지만 숫자는 정확한 예측값이에요
계산 방식이 궁금하다면▾

물을 끓이는 데 필요한 열량 공식(비열 공식)에, 실제 실험으로 확인한 재질별 차이를 반영해서 계산해요.

t = c·m·ΔT / P × k재질 c = 물의 비열, m = 물의 양, ΔT = 온도차, P = 화력(실측 평균 728W), k = 재질별 실측 배수
이론상 --초 재질 배수 -- 기준: 공식실험

재질 배수는 같은 조건에서 실제로 잰 시간이 이론값의 몇 배였는지를 나타내요. 도기처럼 열전달이 느린 재질은 이 값이 더 큽니다.

우리가 실험한 데이터 보기▾

탐구팀이 스톱워치로 직접 측정한 실험 데이터(n=35)를 바탕으로 위 계산이 이루어집니다. 실험 원자료를 그대로 내려받아 확인할 수 있어요.
